# Sabbih website

Static website for **Sabbih (سبّح)**, a dhikr and tasbih counter app for Android.

Pages:
- `index.html`: home
- `privacy.html`: privacy policy (the Google Play privacy policy URL)
- `terms.html`: terms of use
- `delete-data.html`: how to delete app data

There's no build step. Vercel serves the files as they are. `vercel.json` turns on clean URLs, so `/privacy` works as well as `/privacy.html`.
